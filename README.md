## Automatic synchronization

This repository is maintained by [CodeWarsSyncer](https://github.com/MBerkKellecioglu/CodeWarsSyncer). The tool signs in through a local browser, downloads accepted solutions, updates these statistics, and safely pushes new changes to GitHub.
